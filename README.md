📊 End-to-End Data Analytics Project

🔍 Project Summary
This project showcases a full-cycle data analytics workflow, starting from raw data and ending with an interactive dashboard designed for decision-making.
It demonstrates my ability to:
Clean and prepare real-world data using Python
Perform structured analysis using SQL
Translate insights into clear, interactive Power BI dashboards
The project simulates a real analytics task commonly encountered in business and research environments.

Raw datasets often contain inconsistencies, missing values, and noise that make analysis unreliable.
Objective:
To clean, analyze, and visualize the data in order to uncover meaningful insights that can support data-driven decisions.
